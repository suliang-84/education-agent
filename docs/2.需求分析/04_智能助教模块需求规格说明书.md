## 1. 概述

### 1.1 模块目标

智能助教模块（AI Tutor）是中学数理化AI助教微信小程序的核心交互入口，定位为学生学习过程中随时可召唤的"专属思维伙伴"。与个性化AI训练模块"题目驱动"的逻辑不同，智能助教以**对话为主线**，题目是AI教学过程中可调用的工具而非学习全部，核心目标是：

1. **感知学习状态**：持续整合五力画像、错题集、历史对话，掌握学生当前的认知状态与情绪状态
2. **智能决策介入**：AI主动判断何时开口、何时沉默，避免过度干预影响学生独立思考
3. **多维启发引导**：当一种启发角度无效时，自动切换至生活场景、空间想象、故事叙述、音乐节奏、反例论证等不同维度
4. **策略自适应学习**：记录每位学生对各种启发方式的响应情况，逐渐形成专属启发策略画像，AI随历史互动持续调整策略
5. **内驱力培养**：通过苏格拉底式提问与成就感设计，让学生在解题过程中获得"我想通了"的顿悟体验，而非直接给答案

### 1.2 设计原则

| 编号 | 原则 | 说明 |
|------|------|------|
| P-01 | 对话为主，题目为辅 | 学习流程以对话为核心，题目是AI教学工具，而非学习主线 |
| P-02 | AI主动决策介入时机 | AI持续感知学生状态，决定何时说话、何时保持沉默，不被动等待 |
| P-03 | 同一策略无效时主动切换 | 同一启发角度重复2次无效后，AI自动切换至下一个启发维度 |
| P-04 | 策略记忆与个性化 | 对每位学生记录哪种启发方式有效，逐渐形成专属启发偏好档案 |
| P-05 | 不直接给答案 | AI引导学生自主推导，在关键节点给予思路线索而非完整解法 |
| P-06 | 成就感优先 | 交互节奏设计优先考虑学生"我想通了"的获得感 |
| P-07 | 上下文轻量化 | 仅注入必要的状态信息至AI上下文，避免Token冗余 |
| P-08 | 降级有保底 | AI服务不可用时，展示静态知识卡片或预置FAQ，会话不中断 |

### 1.3 用户角色

| 角色标识 | 角色名称 | 使用端 | 核心职责 |
|----------|----------|--------|----------|
| STUDENT | 学生 | 微信小程序 | 发起对话，自由提问，与AI互动学习 |
| SUPER_ADMIN | 超级管理员 | 后台管理系统 | 配置启发策略库，查看会话质量数据，管理对话记录 |

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| 对话会话（Chat Session） | 一次完整的学习对话生命周期单元，从学生开启对话至主动结束或超时关闭 |
| 启发策略（Heuristic Strategy） | AI引导学生思考时采用的维度方法，如生活类比、空间想象、故事叙述等 |
| 策略有效性 | 某一启发策略被使用后，学生在3次问答轮次内产生理解突破的概率 |
| 理解突破（Aha Moment） | 学生在对话中表现出"明白了"的信号，包括：正确复述思路、回答正确后续问题、主动延伸提问 |
| 策略切换阈值 | 同一策略连续使用N次（默认2次）且未产生理解突破，触发自动策略切换 |
| AI介入时机 | AI判断为适合主动发言的时刻，如学生提问、长时沉默、训练错误等 |
| AI沉默策略 | AI判断当前不适合介入的状态，如学生正在思考、刚收到启发仍在消化 |
| 学习状态快照 | 注入AI上下文的结构化信息，含五力画像摘要、当前错题、最近N轮对话 |
| 错题集 | 学生在个性化训练模块中答错的题目集合，含错误记录与分析 |
| 内驱力信号 | 学生主动发起提问、主动复述、主动延伸思考的行为特征 |

### 1.5 前置依赖

- 学生必须已完成微信授权登录，存在有效的 `student_id`
- 学生至少完成一次五力认知测试（存在有效的 `five_power_profiles` 记录），否则智能助教仅提供通用指导，五力感知功能不生效
- 后台已预置至少5种以上启发策略配置
- AI大模型API已接入并配置系统角色Prompt模板

## 2. 应用场景

### 2.1 场景 S-01：学生自由提问（主动发起型）

**场景描述：** 学生在学习过程中遇到不理解的概念或步骤，主动向AI提问。

**触发条件：**
- 学生点击智能助教入口，或在训练模块中点击"问AI"按钮
- 学生在输入框中输入问题并发送

**主流程：**
1. 学生输入问题（如"为什么二次函数的顶点公式是这个？"）
2. 系统读取学习状态快照（五力画像摘要 + 近7天错题摘要 + 近10轮对话）
3. AI生成首轮回应：使用"建构力"导向的启发策略（因该生建构力偏弱），不直接给出公式推导，改用提问引导
4. 学生回应，AI判断学生是否产生理解突破
5. 若未突破，AI切换启发策略（如从代数推导切换至坐标轴图像直觉）
6. 学生产生理解突破，AI给予成就感正反馈，记录本次有效策略

**输入：** 学生自然语言文本（最大500字/条）
**输出：** AI自然语言回复（最大400字/轮）+ 可选题目卡片 + 可选图示说明

**约束：**
- AI首轮回应延迟 ≤ 3秒
- 同一会话累计不超过30轮对话（超出后提示"开启新对话"）

---

### 2.2 场景 S-02：AI主动介入（被动感知型）

**场景描述：** 学生在个性化训练中答题，AI感知到学生连续出错或陷入困境，主动介入对话。

**触发条件（任一满足）：**
- 学生同一知识点连续答错2次（训练模块触发）
- 学生在训练界面停留超过后台配置时长（默认5分钟）未提交答案
- 学生在对话界面超过2分钟无输入（会话已开启状态）

**主流程：**
1. 系统检测到触发条件，向AI上下文推送介入信号 + 错题详情
2. AI判断介入时机是否合适（参见4.3节决策规则）
3. AI主动发送第一条消息（使用问题引导，而非直接解释）
4. 后续流程同 S-01 主流程 Step 4~6

**输入：** 系统事件信号 + 当前题目内容 + 学生答案记录
**输出：** AI主动问候消息 + 引导性问题

**约束：**
- 同一学习会话内AI主动介入不超过3次，防止过度打扰
- 主动介入消息须与正在做的题目内容相关，禁止泛化泛引导

---

### 2.3 场景 S-03：错题复盘对话

**场景描述：** 学生进入错题集，选择某道错题与AI展开针对性复盘对话。

**触发条件：**
- 学生在错题集中点击某道题的"AI复盘"按钮

**主流程：**
1. 系统将错题内容（题目、学生错误答案、正确答案、错误时间）注入AI上下文
2. AI开启复盘会话，采用苏格拉底式提问，从错误根源切入
3. AI引导学生重新分析题目条件（激活洞察力），而非直接讲解解析
4. 学生复述正确思路后，AI确认并追问迁移题（激活迁移力）
5. 会话结束时，AI生成本次复盘摘要（100字以内），记录至错题集复盘记录

**输入：** 错题ID + 学生错误答案 + 五力画像
**输出：** 苏格拉底式问答序列 + 复盘摘要

**约束：**
- 每次错题复盘会话最长持续20分钟（后台可配置），超时后提示保存并退出
- AI在复盘中不得直接给出完整解题步骤，必须通过提问引导学生自主推导

### 2.4 场景 S-04：多维启发切换（策略自适应型）

**场景描述：** 学生对某个知识点持续困惑，AI在同一会话中尝试多种启发维度直至产生理解突破。

**触发条件：**
- 同一概念经过2次相同启发策略引导后，学生仍未产生理解突破

**主流程：**
1. AI检测到策略切换阈值达到（同策略连续2次无效）
2. AI从学生策略有效性画像中查询：该生历史上哪种策略效果最好
3. AI选择下一个启发维度（若画像中有记录则优先高效策略；若无记录则按预设优先级顺序选择）
4. AI以新维度重新引导（如从"公式推导"切换为"生活类比：用斜坡模型解释二次函数的极值"）
5. 记录本次切换事件（原策略标记"本次无效"，新策略标记"启用"）
6. 若产生理解突破，新策略有效性分数+1

**启发策略切换顺序（默认，后台可配置）：**
代数推导 → 生活场景类比 → 坐标几何直觉 → 故事叙述 → 反例证伪 → 空间想象 → 节奏/模式类比 → 简化特例验证

**输入：** 当前策略标识 + 学生策略画像 + 上下文知识点
**输出：** 新策略启发内容 + 策略切换事件记录

---

### 2.5 场景 S-05：成就感正反馈

**场景描述：** 学生在对话中产生理解突破，AI识别并给予定制化正向反馈，强化内驱力。

**理解突破识别信号（双重机制，V1.0并行运行）：**

**机制一：AI语义判断（主）**
- 学生正确回答AI提出的后续验证问题
- 学生主动复述了解题思路（含关键步骤）
- 学生主动提出延伸问题（如"那如果是三次函数呢？"）
- 学生明确表达理解（如"哦！我懂了"、"原来是这样"等）

**机制二：规则兜底（辅，防止AI误判）**
- 学生在当前对话结束后，于训练模块中正确作答同知识点题目（回答正确率≥80%）
- 若规则兜底信号与AI判断结果不一致，以规则兜底为准，修正策略有效性记录

> **V1.1优化计划：** 收集V1.0数据后，通过人工标注复盘分析AI误判率，持续优化语义判断准确性。

**主流程：**
1. AI识别到理解突破信号
2. AI生成个性化成就感反馈（不使用模板化"很棒"，而是具体化："你刚才用'条件推导未知量'这个方法，这正是洞察力的核心！"）
3. 系统记录本次突破事件（知识点ID、使用策略、对话轮次数）
4. 若该知识点来自错题集，自动更新错题状态为"已复盘突破"

**输出：** 个性化成就感反馈文本（50~100字）+ 可选追问题目（用于巩固）

## 3. 整体架构

### 3.1 模块在系统中的位置

```
┌─────────────────────────────────────────────────────────┐
│                    学生端（微信小程序）                    │
│                                                         │
│   ┌──────────────┐    ┌──────────────┐                  │
│   │  个性化AI训练  │    │  五力认知测试  │                  │
│   │   模块        │    │   模块        │                  │
│   └──────┬───────┘    └──────┬───────┘                  │
│          │ 答错/困境信号       │ 五力画像                   │
│          ▼                   ▼                           │
│   ┌──────────────────────────────────────────────────┐  │
│   │              智能助教模块（本模块）                  │  │
│   │                                                  │  │
│   │  对话界面  ←→  学习状态感知引擎  ←→  启发策略库     │  │
│   │                      ↕                           │  │
│   │              AI介入时机决策器                      │  │
│   │                      ↕                           │  │
│   │              学生策略有效性画像                     │  │
│   └──────────────────────┬───────────────────────────┘  │
│                          │ AI调用                        │
└──────────────────────────┼──────────────────────────────┘
                           ▼
             ┌─────────────────────────┐
             │     AI大模型 API         │
             │  (含系统Prompt + 状态快照) │
             └─────────────────────────┘
```

### 3.2 数据流转路径

```
[学生发送消息 / 系统检测触发事件]
        ↓
[学习状态感知引擎] 组装状态快照：
  - 五力画像摘要（最弱2个维度 + 得分）
  - 近7天错题摘要（题目概要 + 五力维度标签，最多5条）
  - 历史对话（最近10轮消息）
  - 当前知识点/题目信息（若存在）
        ↓
[AI介入时机决策器] 判断是否介入（主动介入场景）
        ↓（决定介入）
[启发策略选择器] 查询该生策略有效性画像，选择当前最优策略
        ↓
[AI大模型API] 注入系统Prompt + 状态快照 + 当前策略指令，生成回复
        ↓
[理解突破检测器] 分析学生回复，判断是否产生理解突破
        ↓（未突破且达阈值）      ↓（产生突破）
[策略切换]                  [成就感反馈 + 策略有效性记录更新]
        ↓
[消息存储 + 事件日志]
```

### 3.3 与其他模块的集成关系

| 集成模块 | 集成方向 | 数据内容 | 触发时机 |
|----------|----------|----------|----------|
| 五力认知测试模块 | 读取 | 最新五力画像得分（5个维度）、训练方向标注 | 每次会话开启时同步 |
| 个性化AI训练模块 | 双向 | 读取：当前训练题目、答错记录；写入：AI复盘摘要 | 训练模块触发AI介入时 |
| 错题集（训练子功能） | 双向 | 读取：错题内容；写入：复盘状态、复盘摘要 | 错题复盘场景 |
| 学习记录模块 | 写入 | 会话时长、策略使用统计、理解突破事件数 | 会话结束时 |

**功能点：**

| 功能ID | 功能名称 | 描述 | 优先级 |
|--------|----------|------|--------|

| F-AI-02 | 图片上传 | 学生可上传题目照片，AI识别后纳入上下文（依赖OCR） | P1 |

| F-AI-04 | 题目卡片插入 | AI在回复中可主动插入题目卡片，学生可展开作答 | P1 |
| F-AI-05 | 会话列表 | 查看历史对话列表（按日期倒序，最近30天） | P1 |
| F-AI-06 | 消息点赞/踩 | 学生对AI回复可评价（👍/👎），用于策略有效性辅助数据 | P1 |

### 4.3 AI介入时机决策机制

#### 4.3.1 介入决策规则（何时说话）

| 触发事件 | 触发条件 | AI介入行为 | 优先级 |
|----------|----------|------------|--------|
| 学生发送消息 | 任何时候 | 正常回复 | P0（必须响应） |
| 答题连续错误 | 训练中同题错2次 | 主动发起对话，给出引导性问题 | P0 |
| 答题长时停滞 | 在题目界面≥5分钟无提交 | 发送温和提示："看起来你在认真思考，有没有需要我帮你分析一下条件？" | P1 |
| 对话空白超时 | 会话已开启但≥2分钟无输入 | 发送鼓励信号："有什么困惑，随时告诉我～" | P2 |
| 理解突破信号 | 检测到突破标志 | 给予成就感正反馈 | P0 |

#### 4.3.2 沉默规则（何时不说话）

| 沉默场景 | 判断依据 | 说明 |
|----------|----------|------|
| 学生首次作答正确 | 训练模块判题结果 = 正确 | 不干预，保留学生自信 |
| 刚发出提示后短暂沉默 | 距上条AI消息 < 90秒 | 学生正在消化，不重复催促 |
| 本次会话已介入3次 | ai_chat_session.proactive_count ≥ 3 | 防止过度干预，降为被动响应模式 |
| 学生明确拒绝提示 | 学生发送"我自己想"等拒绝信号 | 进入沉默模式，当前知识点不再主动介入，仅响应学生发起的消息 |
| 已识别到学生正在输入 | 微信小程序输入状态检测 | 等待学生发送完毕再响应 |

#### 4.3.3 沉默拒绝处理

当学生发送拒绝信号（关键词匹配：自己想/不用/我来/别提示等），AI：
1. 回复："好的，你来！有思路了再和我说～"
2. 在当前会话中设置 `silence_mode = true`，该知识点主动介入暂停
3. 学生主动发送消息后，自动解除 `silence_mode`

### 4.4 启发策略库与切换逻辑

#### 4.4.1 标准启发策略库（后台可配置）

| 策略ID | 策略名称 | 适用维度 | 策略描述 | 示例引导话语 |
|--------|----------|----------|----------|-------------|
| S-ANALOGY-LIFE | 生活场景类比 | 洞察力、建构力 | 将抽象数学/物理概念与日常生活场景类比，降低陌生感 | "你有没有注意到，这个和骑自行车上坡的感觉很像？" |
| S-SPATIAL | 空间想象 | 洞察力、推演力 | 引导学生在脑中建立几何或函数的空间直觉 | "你能在脑子里画出这个函数的大概形状吗？" |
| S-STORY | 故事叙述 | 建构力、迁移力 | 将数学问题嵌入故事情境，激发叙事思维 | "假设你是一个侦探，题目给的每个条件都是一条线索…" |
| S-COUNTER | 反例证伪 | 推演力、调适力 | 引导学生思考"如果不这样，会怎样"，通过反例加深理解 | "如果把这个条件去掉，结论还成立吗？举个反例试试？" |
| S-SIMPLIFY | 化简特例 | 调适力 | 在复杂问题上先验证最简单的特殊情形，找到规律 | "如果数字换成1和2，这道题你会做吗？先试试？" |
| S-PATTERN | 节奏/模式感 | 建构力、推演力 | 引导学生发现数学结构的规律性和节奏性 | "你看这个数列，有没有感受到一种节奏？每步变化量是…" |
| S-SOCRATIC | 苏格拉底提问 | 全维度 | 通过连续小问题引导学生自主推导，不给结论 | "首先，题目告诉我们什么？然后，我们要找的是什么？" |
| S-VISUAL | 图示引导 | 洞察力、空间想象 | 建议学生自己画图或提供图示辅助，将抽象转为具象 | "你试着把这道题画出来，把已知量标在图上？" |
| S-ANALOGY-KNOWN | 已知知识类比 | 迁移力 | 将新知识与学生已掌握的知识点类比，建立迁移桥梁 | "这道题和上次我们讨论的等比数列有什么相似之处？" |

#### 4.4.2 策略切换逻辑

```
当前策略使用次数 < 切换阈值（默认2）:
    → 继续使用当前策略，从不同角度再次引导

当前策略使用次数 ≥ 切换阈值:
    1. 查询该生策略有效性画像
    2. 排除已尝试且本次无效的策略
    3. 优先选择：历史有效性评分最高 AND 本次未使用的策略
    4. 若无历史数据，按优先级顺序选择（顺序见4.4.3）
    5. 记录策略切换事件至 ai_strategy_events 表

所有策略均已尝试且无效:
    → AI发出直接提示："这个概念确实有难度，让我直接帮你梳理一下思路。"
    → 进入"直接解析"模式（仍不给完整答案，但给出关键步骤框架）
```

#### 4.4.3 默认策略优先级顺序

（后台可调整）
1. S-SOCRATIC（苏格拉底提问）— 最通用
2. S-SIMPLIFY（化简特例）
3. S-ANALOGY-LIFE（生活场景类比）
4. S-SPATIAL（空间想象）
5. S-VISUAL（图示引导）
6. S-STORY（故事叙述）
7. S-COUNTER（反例证伪）
8. S-PATTERN（节奏/模式感）
9. S-ANALOGY-KNOWN（已知知识类比）

### 4.5 学生策略有效性画像

#### 4.5.1 功能描述

系统为每位学生维护一份启发策略有效性档案，记录该生对每种策略的历史响应情况，AI在选择策略时优先参考此档案，实现个性化策略适配。

**V1.0：后台静默积累**，学生端不展示档案数据，仅用于AI内部策略选择。
**V1.1：以"学习风格"形式对学生展示**，如"你更容易通过生活举例理解""你更喜欢先看图再理解"，结合成就感设计增强学生自我认知。

#### 4.5.2 有效性评分规则

| 事件 | 分数变化 |
|------|----------|
| 使用该策略后，学生在3轮内产生理解突破 | 有效次数 +1 |
| 使用该策略，达切换阈值仍未突破，被切换 | 无效次数 +1 |
| 学生对使用该策略的AI消息点赞 | 正向评价次数 +1 |
| 学生对使用该策略的AI消息踩 | 负向评价次数 +1 |

**有效性评分（Effectiveness Score）计算：**
```
ES = (有效次数 + 正向评价次数 × 0.5) / (总使用次数 + 1) × 100
```

**时间衰减：V1.0不启用**，所有历史数据等权重参与计算。
**V1.1引入衰减机制：** 3个月以上的历史数据权重衰减至50%（`last_used_at` 距今 > 90天的记录，`effective_count` 和 `positive_ratings` 乘以0.5后再参与计算），反映学生学习偏好的动态变化。

#### 4.5.3 档案更新时机

- 每次对话会话结束后，异步批量更新（不阻塞主流程）
- 更新范围：本次会话中使用过的所有策略

#### 4.5.4 冷启动处理

- 新用户（无历史策略数据）：使用默认优先级顺序（见4.4.3）
- 少量数据用户（总使用次数 < 3次）：有效性评分权重降低，混合使用默认顺序与历史数据（各50%权重）

## 7. 约束条件汇总

### 7.1 性能约束

| 指标 | 要求 |
|------|------|
| AI首字响应时间 | ≤ 3秒（P95） |
| 学习状态快照组装时间 | ≤ 500ms |
| 单会话最大消息轮数 | 30轮 |
| 单条学生消息最大长度 | 500字 |
| 单条AI回复最大Token | 800 Token |
| 单次上下文输入上限 | 1200 Token |

### 7.2 业务约束

| 约束 | 规则 |
|------|------|
| AI不直接给答案 | AI回复中禁止出现完整解题步骤，必须通过启发引导，直接解析模式仍只给关键框架 |
| 主动介入频率限制 | 每次学习会话（含训练模块）AI主动介入不超过3次 |
| 策略切换冷却 | 同一策略切换后，不得在2轮内切回同一策略 |
| 错题复盘时长 | 单次复盘会话最长20分钟，超时自动结束并归档 |
| 重测频率（针对五力测试） | 不在本模块处理，引用测试模块约束：每30天最多1次 |
| 多设备会话限制 | 同一学生同时最多存在1个 active 会话；第二台设备开启对话时，原设备会话自动关闭（状态置为 completed）并归档，原设备展示提示："你在另一台设备开启了新对话，本次对话已自动保存" |
| 数据保留 | 用户注销后30天内完全清除AI交互记录（遵循个人信息保护法） |
| 未成年人保护 | 产品内无广告、无社交关系分享，AI内容安全层对涉及敏感话题的消息进行过滤 |

### 7.3 技术约束

| 约束 | 规则 |
|------|------|
| 多家AI供应商支持 | 支持切换AI服务商，系统Prompt和调用参数通过配置文件驱动 |
| 上下文管理 | 历史对话保留最近10轮；超出10轮时由后端生成100字以内的压缩摘要注入上下文首部，保留关键推导节点，避免对话连续性断裂（此摘要生成为独立异步调用，不计入主流程Token限额） |
| 策略有效性更新 | 异步批量更新，不阻塞主流程 |
| OCR能力 | V1.0限制印刷体识别，手写体识别为P2功能 |
| 数学公式渲染 | 前端集成KaTeX渲染LaTeX格式公式 |
