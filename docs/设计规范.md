# MESH Admin 设计规范 v1.0

> 基于参考图分析提取，适配 AI 助教后台管理系统

---

## 1. 设计风格定位

**关键词：** 柔和活力（Soft Vibrant）· 友好专业 · 教育科技感

这套设计语言的核心气质是：用大面积薰衣草紫背景 + 纯白卡片构建层次，用高饱和热粉色作为唯一行动召唤色，用圆角到极致的 border-radius 传递亲切感。它不是冰冷的工具型 SaaS，也不是沉闷的政府系统，而是一个让管理员愿意每天打开的、有温度的教育平台后台。

## 3. 字体排印

### 3.1 字体家族

```css
--font-sans: 'Inter', 'PingFang SC', 'Hiragino Sans GB', system-ui, sans-serif;
--font-mono: 'JetBrains Mono', 'SF Mono', Consolas, monospace;
```

> 参考图使用圆润感强的无衬线字体（接近 Inter 或 Nunito）。中文环境下 PingFang SC 与 Inter 配合圆润和谐。

### 3.2 字阶

| 角色 | 大小 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Display | 28px | 700 | 1.2 | 页面主标题（仅用一次） |
| Title 1 | 20px | 700 | 1.3 | 区块大标题 |
| Title 2 | 15px | 600 | 1.4 | 卡片标题、弹窗标题 |
| Body | 14px | 400 | 1.6 | 正文内容 |
| Small | 13px | 400/500 | 1.5 | 表格内容、标签 |
| Caption | 11.5px | 500 | 1.4 | 分类标签、上标 |
| Mono | 12.5px | 400 | 1.6 | 数字、代码、ID |

### 3.3 特殊处理

- **数字一律使用等宽字体**（Mono），配合 `font-variant-numeric: tabular-nums`
- **分类标签**（如 INSIGHT、DRAFT）：全大写 + `letter-spacing: 0.06em` + Caption 字号
- **导航文字**：Small 13px，激活状态 font-weight: 600，普通状态 400

## 4. 圆角系统

这是本设计最显著的特征——**圆角要圆到极致**，传递亲切、现代的教育科技感。

| Token | 值 | 用途 |
|-------|-----|------|
| `--r-xs` | `4px` | Badge内部 |
| `--r-sm` | `8px` | 小徽章、小标签 |
| `--r-md` | `10px` | 输入框、小按钮 |
| `--r-lg` | `14px` | 一般按钮 |
| `--r-xl` | `18px` | 卡片、侧边栏面板 |
| `--r-2xl` | `24px` | 弹窗 |
| `--r-pill` | `9999px` | 主CTA按钮、搜索框、大标签 |

> **核心规则：** 主 CTA 按钮（Save、Publish、Login）必须使用 `--r-pill`（胶囊形）。输入框使用 `--r-md`（略圆）。卡片使用 `--r-xl`。

## 6. 组件规范

### 6.1 按钮

| 类型 | 背景 | 文字 | 圆角 | 用途 |
|------|------|------|------|------|
| Primary (CTA) | `#F43F7E` | 白色 | `--r-pill` | 最重要操作：发布、保存、确认 |

## 12. 应用规则总结

### 必须遵守

1. **页面底色永远是薰衣草紫 `#E8ECF8`**，绝不用纯白或灰色做底色
2. **主CTA按钮永远是热粉色 `#F43F7E`，胶囊形**
3. **所有卡片圆角 ≥ 18px**，按钮/徽章/导航项也要保持圆润
4. **阴影使用靛蓝色调**，不用纯灰阴影
5. **激活导航项用整块靛蓝淡色背景**，不用左侧色条方案
6. **数字和 ID 使用等宽字体**

### 避免出现

1. 暗色系（黑色、深灰）背景（仅图表 tooltip 允许深色）
2. 方形按钮（所有交互元素必须有圆角，主按钮为胶囊）
3. 纯灰色阴影（阴影必须带有靛蓝品牌色调）
4. 在主 CTA 和次要元素上同时使用热粉色
5. 表格行 hover 用普通灰，改用淡薰衣草 `#F5F7FF`
