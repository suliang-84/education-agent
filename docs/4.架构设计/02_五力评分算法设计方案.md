## 1. 算法总览与设计哲学

### 1.1 核心输入输出

```
输入：
  20道测试题的答题记录（选项 + 时长 + 修改次数）
  学生基本信息（年级）
  历史测试记录（若存在）
  后续训练答题记录（动态更新阶段）

输出：
  ability_score[5]      五力能力分向量，0~100，来自标准答案题
  preference_score[5]   五力认知入口分向量，0~100，总和=100
  final_score[5]        综合分向量，0~100，用于雷达图展示
  profile               AI可读画像JSON（薄弱项/优势入口/推荐模式）
```

### 1.2 双维度独立设计原则

> **最重要的设计约束：** 能力分（ability）和认知入口分（preference）是两个正交维度，描述的是不同事物，必须独立计算、独立存储、独立使用，不能混合或互相替代。

| 维度 | 来源题目 | 回答的问题 | 下游用途 |
|------|----------|-----------|----------|
| `ability_score` | 10道标准答案题 | 学生**实际能做到什么** | 决定补弱目标（TRAIN_WEAKNESS 的 target） |
| `preference_score` | 10道无唯一答案题 | 学生**习惯从哪里进入** | 决定教学入口（AI Prompt 的 preferred_force） |
| `final_score` | 两者加权合成 | 综合表现水平 | 前台雷达图可视化 |

## 3. Module A：能力分计算（ability_score）

### 3.1 设计思路

标准答案题测量"能做到什么"，采用三步计算：**基础得分 → 时长加权 → 历史衰减**。

**关键约束：** 每种力仅有2道题，样本极小，单题权重很高，算法设计需要在信号敏感性和稳定性之间平衡。

---

### 3.2 Step A-1：基础得分（Base Score）

#### 选择类题目（单选、情景判断）

```
base_score_i = option_scores[selected] / max(option_scores) × power_weight

其中：
  option_scores[selected] = 学生所选选项的预设得分（如选B，得7分）
  max(option_scores)      = 该题最高可得分（通常为10）
  power_weight            = 该题对目标五力的贡献权重（0.1~1.0，后台配置）

result: base_score_i ∈ [0, 1]
```

**示例：**
```
题01（洞察力，单选题）：
  option_scores = {A:10, B:7, C:4, D:1}
  学生选 B → base_score = 7 / 10 × 1.0 = 0.70
```

#### 多选题

```
base_score_i = Σ(option_scores[k] for k in selected) / max_possible × power_weight

其中 max_possible = 允许选择数量下所有最高分选项之和

示例：允许选2个，最高2个选项得分为 10+7=17
  学生选了 A(10) 和 C(4) → score = (10+4)/17 × 1.0 = 0.824
```

#### 文字类题目（填空、简答、计算）

```
base_score_i = answer_quality × power_weight

其中 answer_quality ∈ [0, 1]，由关键词匹配 + AI语义评分输出：
  关键词匹配得分 q_keyword ∈ {0, 0.5, 1.0}（无匹配/部分匹配/完全匹配）
  AI语义得分    q_semantic ∈ [0, 1]（异步，30秒内返回）

  若 AI语义评分可用：
    answer_quality = max(q_keyword, q_semantic)  ← 取较高值
  若 AI超时降级：
    answer_quality = q_keyword
```

---

### 3.3 Step A-2：时长加权（Time Bonus）

**设计意图：** 在参考时间内完成的学生，说明认知加工更流畅，给予小幅加分。超时过多的不扣分（避免焦虑惩罚）。

```
time_ratio = max(0, (reference_time_sec - time_spent_sec) / reference_time_sec)

time_bonus_i = base_score_i × time_bonus_coefficient × time_ratio

time_weighted_score_i = base_score_i + time_bonus_i

其中：
  time_bonus_coefficient = 0.10（最高加 10%，后台可配置）
  time_ratio ∈ [0, 1]，超时则为0（不扣分）
```

**注意事项：**

```
边界处理：
  ① 若 time_spent_sec < 5（极快作答）：
     标记为 rushed=true，time_ratio 清零（不给时长加分，但不扣分）
  ② 若 time_spent_sec > 600（超长）：
     截断为 600s，time_ratio=0

结果：time_weighted_score_i ∈ [0, 1.1]（基础1.0 + 最多10%加成）
```

---

### 3.4 Step A-3：历史衰减加权（History Decay）

**设计意图：** 重测时，新结果和历史结果共同影响最终画像，防止单次测试的偶然性主导画像。

```
若是首次测试：
  final_raw_score_i = time_weighted_score_i   ← 直接使用

若是第 N 次测试（N ≥ 2）：
  final_raw_score_i = time_weighted_score_i × (1 - history_decay)
                    + last_final_score_i × history_decay

其中：
  history_decay = 0.30（新结果权重70%，历史结果权重30%，后台可配置）
  last_final_score_i = 上次测试该力的最终归一化得分（0~1）
```

**设计示意：**
```
第1次测试：洞察力原始 = 0.70 → final_raw = 0.70
第2次测试：洞察力原始 = 0.50
  final_raw = 0.50 × 0.70 + 0.70 × 0.30 = 0.35 + 0.21 = 0.56
```

---

### 3.5 Step A-4：五力能力分汇总

**每种力有2道标准答案题，分别计算后加权平均：**

```
每题权重 w_q（由题目配置的 power_weight 决定）：
  若两题 power_weight 均为 1.0，则等权重

ability_raw(force) = Σ(final_raw_score_i × w_qi) / Σ(w_qi)
                   = (final_raw_Q1 × w_Q1 + final_raw_Q2 × w_Q2) / (w_Q1 + w_Q2)

ability_score(force) = round(ability_raw(force) × 100)

result: ability_score(force) ∈ [0, 100]
```

**完整示例（洞察力，两题）：**

```
题01：base=0.70，时长比=0.50 → time_weighted = 0.70 × (1 + 0.10×0.50) = 0.735
题02：base=0.30，时长比=0.00 → time_weighted = 0.30（超时，无加成）

首次测试，无历史：
  ability_raw(INSIGHT) = (0.735 × 1.0 + 0.30 × 1.0) / 2 = 0.5175
  ability_score(INSIGHT) = round(0.5175 × 100) = 52
```

## 4. Module B：认知入口分计算（preference_score）

### 4.1 设计思路

无唯一答案题测量"习惯从哪里进入"，每个选项背后是五维权重向量，学生的选择累积揭示其认知倾向。最终结果是相对偏好分布（总和=100），而非绝对能力分。

---

### 4.2 Step B-1：单题权重向量提取

```
对于每道无唯一答案题 q（共10道），学生选择选项 k：

  contribution_vector(q) = option_force_weights[k]
  = {
      INSIGHT: w_insight,
      STRUCTURE: w_structure,
      INFERENCE: w_inference,
      ADAPTATION: w_adaptation,
      TRANSFER: w_transfer
    }

约束：sum(contribution_vector) ≈ 1.0（每题各力权重之和为1）
```

**示例（题03，学生选B）：**
```
contribution_vector(Q03) = {
  INSIGHT: 0.10, STRUCTURE: 0.65, INFERENCE: 0.10,
  ADAPTATION: 0.10, TRANSFER: 0.05
}
```

---

### 4.3 Step B-2：调适力题特殊处理

**设计背景：** 题15、16是调适力专项题，所有选项的调适力权重均最高（0.45~0.50），同时揭示"靠什么方式调适"。这些题不能简单地按单一权重处理，需要保留双重信号。

```
对于调适力题（Q15、Q16）：
  保持原始权重向量不变（调适力最高，其次是该选项揭示的辅助力）
  不做特殊修正，累积过程与其他题相同

例：题15学生选A（洞察驱动的调适）：
  contribution = {INSIGHT: 0.40, STRUCTURE: 0.05, INFERENCE: 0.05,
                  ADAPTATION: 0.45, TRANSFER: 0.05}

这道题同时贡献了：
  调适力倾向 +0.45
  洞察力倾向 +0.40 ← 揭示"该学生倾向用洞察方式来调适"
```

---

### 4.4 Step B-3：累积与归一化

```
Step 1：10道题权重向量逐题累加

  raw_preference[force] = Σ contribution_vector(q)[force]  for q in 10 open questions

Step 2：归一化到0~100

  total = Σ raw_preference[force] for all forces  ← 理论值 ≈ 10.0

  preference_score[force] = round(raw_preference[force] / total × 100)

约束：Σ preference_score[force] = 100（相对偏好分布，总和恒为100）

result: preference_score[force] ∈ [0, 100]，总和 = 100
```

**完整示例：**
```
10题累积：
  INSIGHT: 3.80, STRUCTURE: 2.60, INFERENCE: 1.70, ADAPTATION: 0.90, TRANSFER: 1.00
  total = 10.00

preference_score:
  INSIGHT:    round(3.80/10 × 100) = 38
  STRUCTURE:  round(2.60/10 × 100) = 26
  INFERENCE:  round(1.70/10 × 100) = 17
  ADAPTATION: round(0.90/10 × 100) = 9
  TRANSFER:   round(1.00/10 × 100) = 10
  ────────────────────────────────────────
  总和 = 100 ✓

注意：若 round 后总和 ≠ 100（因舍入误差），对差值最大的力±1修正。
```

---

### 4.5 入口倾向识别

```
# 第一认知入口：preference_score 最高的力
primary_entry = argmax(preference_score)

# 第二认知入口：preference_score 第二高的力
secondary_entry = argmax(preference_score, exclude=primary_entry)

# 冷启动保护：若最高入口分 < 25（接近均匀分布），
# 视为"入口不明显"，使用默认策略而非强制指定入口
if preference_score[primary_entry] < 25:
    entry_confidence = "LOW"    # AI教学不强制使用特定入口
else:
    entry_confidence = "HIGH"
```

## 5. Module C：综合分合成（final_score）

### 5.1 加权合成公式

```
final_score[force] = round(
    ability_score[force] × objective_weight
  + preference_score[force] × preference_weight
)

其中：
  objective_weight   = 0.70（能力分权重）
  preference_weight  = 0.30（入口分权重）

result: final_score[force] ∈ [0, 100]
```

### 5.2 设计说明

**为什么是 70/30？**

| 考量 | 说明 |
|------|------|
| 能力分占主导 | 教学决策以"实际能力"为核心，入口偏好为辅助 |
| 入口分有参考价值 | 入口分携带了思维方式信息，不能完全忽略 |
| 不对称性 | ability 来自对/错测量，信号更可靠；preference 是相对分布，精度较低 |
| 配置化 | 两个权重均后台可调，上线后根据真实数据验证效果 |

**用途限制：** final_score 仅用于前台雷达图展示。AI 教学决策必须分别使用 ability_score 和 preference_score 原始值，不使用 final_score。

### 5.3 完整示例

```
输入：
  INSIGHT:    ability=82, preference=38
  STRUCTURE:  ability=47, preference=26
  INFERENCE:  ability=74, preference=17
  ADAPTATION: ability=58, preference=9
  TRANSFER:   ability=51, preference=10

计算：
  final(INSIGHT)    = round(82×0.70 + 38×0.30) = round(57.4+11.4) = 69
  final(STRUCTURE)  = round(47×0.70 + 26×0.30) = round(32.9+7.8)  = 41
  final(INFERENCE)  = round(74×0.70 + 17×0.30) = round(51.8+5.1)  = 57
  final(ADAPTATION) = round(58×0.70 + 9×0.30)  = round(40.6+2.7)  = 43
  final(TRANSFER)   = round(51×0.70 + 10×0.30) = round(35.7+3.0)  = 39
```

## 6. Module D：画像分析与标签生成

### 6.1 等级分类

**基于 ability_score（能力分）进行等级判定：**

```python
def classify_level(ability_score: int) -> str:
    """
    等级分类基于ability_score（非final_score）
    统一阈值，全系统一致（参见系统交互协议规范 §7.1）
    """
    if ability_score < 50:
        return "weak"      # 重点强化（🔴 红色）
    elif ability_score < 65:
        return "medium"    # 需改进（🟡 黄色）
    elif ability_score < 80:
        return "good"      # 良好（🟢 绿色）
    else:
        return "strong"    # 优势（💚 深绿）
```

### 6.2 薄弱项识别

```python
def identify_weakness(ability_scores: dict) -> dict:
    """
    薄弱项：ability_score < weak_threshold（默认60）的力
    按分数从低到高排序取前三
    """
    weak_threshold = 60  # 后台可配置

    weak_forces = [
        (force, score) for force, score in ability_scores.items()
        if score < weak_threshold
    ]
    weak_forces.sort(key=lambda x: x[1])  # 分数越低越优先

    result = {
        "primary_weakness": weak_forces[0][0] if len(weak_forces) >= 1 else None,
        "secondary_weakness": weak_forces[1][0] if len(weak_forces) >= 2 else None,
        "has_weakness": len(weak_forces) > 0
    }
    return result
```

### 6.3 优势与入口识别

```python
def identify_strength_and_entry(ability_scores: dict,
                                 preference_scores: dict) -> dict:
    """
    优势力：ability_score 最高的力（不要求>75，始终存在）
    优势入口：preference_score 最高的力
    两者独立识别，不互相影响
    """
    primary_strength = max(ability_scores, key=ability_scores.get)

    primary_entry = max(preference_scores, key=preference_scores.get)
    secondary_entry = sorted(preference_scores,
                             key=preference_scores.get, reverse=True)[1]

    return {
        "primary_strength": primary_strength,
        "primary_learning_entry": primary_entry,
        "secondary_learning_entry": secondary_entry
    }
```

### 6.4 能力-入口错位分析

**设计意图：** 错位信息对 AI 教学策略有重要指导意义，直接影响 Prompt 生成逻辑。

```python
def analyze_deviation(ability_scores: dict,
                      preference_scores: dict) -> list:
    """
    错位分析：对每种力，计算 ability 和 preference 的差值方向
    gap > 20：显著错位，需要标注
    """
    deviations = []

    for force in ["INSIGHT", "STRUCTURE", "INFERENCE", "ADAPTATION", "TRANSFER"]:
        ability = ability_scores[force]
        preference = preference_scores[force]
        gap = ability - preference  # 正数=能力>偏好；负数=偏好>能力

        if abs(gap) > 20:  # 显著错位阈值，后台可配置
            deviation_type = classify_deviation(ability, preference)
            deviations.append({
                "force": force,
                "ability": ability,
                "preference": preference,
                "gap": gap,
                "type": deviation_type,
                "teaching_hint": generate_teaching_hint(force, deviation_type)
            })

    return deviations

def classify_deviation(ability: int, preference: int) -> str:
    """
    四种错位类型，对应不同教学策略
    """
    high_ability   = ability >= 65
    high_preference = preference >= 25  # 相对偏好>均值(20)则为高

    if not high_ability and high_preference:
        return "LOW_ABILITY_HIGH_PREFERENCE"    # 喜欢但能力弱：顺应偏好+基础训练
    elif high_ability and not high_preference:
        return "HIGH_ABILITY_LOW_PREFERENCE"    # 能强但不主动用：引导发挥潜力
    elif high_ability and high_preference:
        return "MATCHED_STRONG"                 # 稳定优势：作为教学入口
    else:
        return "MATCHED_WEAK"                   # 真正薄弱：从基础抓起

def generate_teaching_hint(force: str, deviation_type: str) -> str:
    hints = {
        "LOW_ABILITY_HIGH_PREFERENCE": f"学生倾向用{force}方式思考，但能力尚弱；顺应其偏好给予针对性练习",
        "HIGH_ABILITY_LOW_PREFERENCE": f"学生{force}能力较强但较少主动激活；AI应主动引导从此维度切入",
        "MATCHED_STRONG": f"{force}为该学生稳定优势，优先作为借强补弱的入口力",
        "MATCHED_WEAK": f"{force}能力和偏好均弱，需系统性基础训练，不宜作为教学入口"
    }
    return hints[deviation_type]
```

```python
def recommend_mode(ability_scores: dict, knowledge_point_history: int = 0) -> str:
```

## 7. Module E：动态画像更新算法

### 7.1 设计背景

初始测试画像（20题）样本量小（每力仅2道标准题），存在较大随机误差。后续训练答题数据（每次训练5~10题，每力多题）能提供更丰富、更真实的能力信号，应持续修正初始画像。

**两层画像架构：**

```
test_profiles      ← 初始测试画像（来自五力测试模块）
training_profiles  ← 训练行为画像（来自个性化训练模块，滚动更新）

综合能力查询 = training × 0.6 + test × 0.4
```

---

### 7.2 训练数据累积规则

**每次训练会话结束后，触发异步更新（Session-level Batch Update）：**

```python
def update_training_profile(student_id: str,
                            session_answer_records: list,
                            current_profile: dict) -> dict:
    """
    基于本次训练会话的答题记录，滚动更新五力训练画像
    采用指数加权移动平均（EWMA），避免历史数据被单次异常覆盖
    """
    # Step 1：从本次会话提取各力信号
    session_signals = extract_session_signals(session_answer_records)

    # Step 2：EWMA更新（decay=0.30，即新数据权重30%）
    decay = current_profile.get("decay_coefficient", 0.30)  # 后台可配置

    updated_scores = {}
    for force in FIVE_FORCES:
        if force not in session_signals or session_signals[force]["count"] == 0:
            updated_scores[force] = current_profile["ability"][force]  # 无数据则不变
            continue

        session_score = session_signals[force]["accuracy"] * 100  # 本次正确率→分数
        current_score = current_profile["ability"][force]

        # 新权重=decay，历史权重=(1-decay)
        updated_scores[force] = round(
            session_score * decay + current_score * (1 - decay)
        )

    return updated_scores

def extract_session_signals(records: list) -> dict:
    """
    从答题记录中提取每种力的正确率信号
    """
    signals = {force: {"correct": 0, "total": 0} for force in FIVE_FORCES}

    for record in records:
        force = record["power_type"]  # 本题主训练力
        signals[force]["total"] += 1
        if record["is_correct"]:
            signals[force]["correct"] += 1

    for force in FIVE_FORCES:
        total = signals[force]["total"]
        if total > 0:
            signals[force]["accuracy"] = signals[force]["correct"] / total
            signals[force]["count"] = total

    return signals
```

```python
def get_current_ability(student_id: str) -> dict:

        return test_profile["ability"]

    for force in FIVE_FORCES:

            train_profile["ability"][force] * MIX_RATIO_TRAIN
          + test_profile["ability"][force]  * MIX_RATIO_TEST

    return combined
```

## 8. Module F：选题权重生成

### 8.1 设计目的

从当前五力画像出发，生成本次训练的选题权重向量，决定"练什么"。

### 8.2 权重计算算法

```python
def calculate_selection_weights(current_ability: dict,
                                training_mode: str,
                                preferred_force: str = None) -> dict:
    """
    生成五力选题权重，决定各力题目的比例
    """
    BASE_WEIGHT = 0.20  # 每力基础权重（五力均分）
    weights = {force: BASE_WEIGHT for force in FIVE_FORCES}

    if training_mode == "TRAIN_WEAKNESS":
        # 补弱模式：按薄弱程度加权
        for force, ability in current_ability.items():
            if ability < 50:
                weights[force] += 0.40   # 严重薄弱：+40%
            elif ability < 65:
                weights[force] += 0.20   # 一般薄弱：+20%
            # ability >= 65：不加权

    elif training_mode == "LEARN_BY_STRENGTH":
        # 一通百通：优势入口力大幅提权
        if preferred_force:
            weights[preferred_force] = 0.50  # 优势入口力占50%
            # 剩余50%均分给其他四力
            other_forces = [f for f in FIVE_FORCES if f != preferred_force]
            for f in other_forces:
                weights[f] = 0.50 / 4

    # 归一化，确保总和=1.0
    total = sum(weights.values())
    weights = {f: w / total for f, w in weights.items()}

    return weights

def generate_question_counts(weights: dict, total_questions: int = 5) -> dict:
    """
    将权重转换为各力题目数量（整数）
    """
    raw_counts = {f: weights[f] * total_questions for f in FIVE_FORCES}

    # 取整策略：先取floor，再补足差值给权重最高的力
    counts = {f: int(c) for f, c in raw_counts.items()}
    remainder = total_questions - sum(counts.values())

    # 按小数部分从大到小排序，补足余数
    sorted_forces = sorted(raw_counts, key=lambda f: raw_counts[f] - counts[f],
                           reverse=True)
    for i in range(remainder):
        counts[sorted_forces[i]] += 1

    return counts
```

## 9. 异常检测与数据质量保障

### 9.1 作答质量信号

在评分前，对每次测试会话进行质量检测，输出质量标记：

```python
def assess_response_quality(answers: list, questions: list) -> dict:
    """
    检测作答行为异常，输出质量报告
    """
    quality = {
        "is_valid": True,
        "flags": [],
        "confidence_penalty": 0.0
    }

    total_time = sum(a["time_spent_sec"] for a in answers)
    rushed_count = sum(1 for a in answers if a["time_spent_sec"] < 5)
    modify_count = sum(a["modify_count"] for a in answers)

    # 规则1：全程时间过短（<5分钟），疑似随意作答
    if total_time < 300:
        quality["flags"].append("TOTAL_TIME_TOO_SHORT")
        quality["confidence_penalty"] += 0.20

    # 规则2：超过30%的题极速作答（<5秒）
    if rushed_count / len(answers) > 0.30:
        quality["flags"].append("TOO_MANY_RUSHED_ANSWERS")
        quality["confidence_penalty"] += 0.15

    # 规则3：总修改次数异常（可能频繁改变主意）
    if modify_count > len(answers) * 2:
        quality["flags"].append("HIGH_MODIFY_COUNT")
        quality["confidence_penalty"] += 0.10

    # 若置信度惩罚超过50%，标记为低可信
    if quality["confidence_penalty"] >= 0.50:
        quality["is_valid"] = False
        quality["flags"].append("LOW_CONFIDENCE_RESULT")

    return quality
```

### 9.2 画像置信度计算

```python
def calculate_confidence(ability_scores: dict, quality: dict,
                         is_first_test: bool = True) -> dict:
    """
    画像置信度：反映当前五力画像的可靠程度
    影响因素：样本量（每力2题）、作答质量、历史测试次数
    """
    BASE_CONFIDENCE = 0.65  # 2题/力时基础置信度（样本较小）

    # 作答质量惩罚
    confidence = BASE_CONFIDENCE - quality["confidence_penalty"]

    # 首次测试置信度额外-0.10（缺乏校准参考）
    if is_first_test:
        confidence -= 0.10

    return {
        "score": max(0.0, min(1.0, confidence)),
        "level": "HIGH" if confidence > 0.7 else "MEDIUM" if confidence > 0.4 else "LOW",
        "note": "2道题/力样本量有限，建议完成10+次训练后画像趋于稳定"
    }
```

### 9.3 数据一致性校验

```python
def validate_scores(ability_scores: dict, preference_scores: dict,
                    final_scores: dict) -> bool:
    """
    输出前校验数值合法性
    """
    for force in FIVE_FORCES:
        assert 0 <= ability_scores[force] <= 100, f"{force} ability越界"
        assert 0 <= preference_scores[force] <= 100, f"{force} preference越界"
        assert 0 <= final_scores[force] <= 100, f"{force} final越界"

    preference_sum = sum(preference_scores.values())
    assert 99 <= preference_sum <= 101, f"preference总和异常：{preference_sum}"

    return True
```

| `rushed_ratio_threshold` | 0.30 | [0.2, 0.5] | 极速题占比超过此值触发质量预警 |
| `is_correct_threshold` | 0.70 | [0.5, 0.9] | 文字题答案质量系数 ≥ 此值判为正确 |
| `option_force_weights` | 见题库 | 各力权重和=1 | 每题各选项的五力权重向量，按题目独立配置 |

## 12. 复杂度与性能分析

### 12.1 时间复杂度

| 计算模块 | 复杂度 | 说明 |
|----------|--------|------|
| ability_score 计算 | O(N_q) | N_q=10（标准答案题数，常数） |
| preference_score 计算 | O(N_o × 5) | N_o=10（开放题数），5种力，常数 |
| 画像分析与标签 | O(5) | 五力遍历，常数 |
| 动态画像更新 | O(N_session × 5) | N_session = 本次训练题数（5~20） |
| 选题权重生成 | O(5) | 五力遍历，常数 |
| **总体** | **O(1)** | **全部为常数级计算，实时性极好** |

### 12.2 性能目标

| 接口 | SLA | 说明 |
|------|-----|------|
| 同步评分（测试完成后） | ≤ 3秒 | ability + preference + final 全部同步计算 |
| 画像生成（JSON输出） | ≤ 500ms | 基于上述结果的标签分析 |
| 训练画像更新 | ≤ 5分钟 | 异步处理，不阻塞用户操作 |
| 综合能力查询 | ≤ 100ms | 查询缓存 + 实时合成 |
| AI文字解读生成 | ≤ 30秒 | 异步，骨架屏占位，完成后填充 |

### 12.3 缓存策略

```
画像缓存（Redis）：
  key:   student_ability:{student_id}
  value: 最新综合能力JSON
  TTL:   1小时（训练后主动更新）

选题权重缓存：
  key:   question_weights:{student_id}:{knowledge_point_id}
  TTL:   30分钟（知识点切换后失效）
```

## 13. 版本迭代规划

### V1.0（当前设计）

- 标准答案题：0/1 二值计分
- 时长加权：简单线性加成
- 历史衰减：线性加权
- 训练更新：EWMA 简单版本
- 样本量不足：每力仅2道标准题，画像置信度偏低

### V1.1（优化方向）

- **部分正确计分：** 文字题引入 0/0.5/1.0 三档，提升评分精度
- **置信区间输出：** 基于各力实际题数，计算能力分的置信区间，告知 AI 不确定性
- **时间信号细化：** 区分"快速正确"（流畅掌握）vs"慢速正确"（挣扎后掌握）vs"快速错误"（冲动决策）
- **连续表现奖励：** 连续3次会话同力正确率≥90%，触发小幅额外加分

### V2.0（长期演进）

- **自适应测题（CAT）：** 根据前几题作答情况动态调整后续题目难度，减少总题数至15题，提升精度
- **多维信号融合：** 引入在线学习（Online Learning），实时更新画像
- **跨力迁移建模：** 当一种力显著提升后，预测关联力的联动变化
