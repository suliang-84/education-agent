## 1. 通用规范

### 1.1 基础信息

| 项目 | 说明 |
|------|------|
| Base URL（小程序） | `https://api.mesh-edu.com/api/v1` |
| Base URL（管理后台） | `https://api.mesh-edu.com/api/v1/admin` |
| 协议 | HTTPS |
| 数据格式 | `Content-Type: application/json; charset=UTF-8` |
| 字符集 | UTF-8 |
| 时间格式 | ISO 8601，`2026-08-30T10:00:00Z`（UTC） |

### 1.2 统一响应格式

所有接口的返回结构统一如下：

```json
{
  "status": "success",
  "code": 0,
  "msg": "操作成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | string | 固定三值：`success`（成功）/ `fail`（业务失败）/ `error`（系统错误） |
| `code` | integer | 0 = 成功；非0 = 错误码（见 §1.4） |
| `msg` | string | 面向用户的提示信息（中文） |
| `data` | object/array/null | 业务数据体；成功时包含实际数据，失败时为 null |

**分页响应结构（列表接口）：**

```json
{
  "status": "success",
  "code": 0,
  "msg": "操作成功",
  "data": {
    "list": [],
    "total": 100,
    "has_more": true,
    "next_cursor": 80
  }
}
```

> 所有列表接口采用 **Keyset Pagination（游标分页）**，禁止使用 OFFSET 分页。

### 1.3 认证方式

```
Authorization: Bearer {access_token}
```

- **小程序端**：access_token 有效期 7 天，refresh_token 有效期 30 天，静默续期
- **管理后台**：access_token 有效期 8 小时，无 refresh_token，到期重新登录
- **Token 格式**：RS256 签名的 JWT

**无需 Token 的接口（白名单）：**
- `POST /api/v1/auth/wx-login`
- `POST /api/v1/auth/admin-login`
- `POST /api/v1/auth/sms/send`
- `GET /health`

### 1.4 错误码规范

| 前缀 | 范围 | 模块 |
|------|------|------|
| `0` | — | 成功 |
| `AUTH-*` | 身份认证 | Token 过期/无效/权限不足 |
| `LOGIN-*` | 登录流程 | 密码错误/账号锁定 |
| `SMS-*` | 短信验证码 | 频率限制/验证码错误 |
| `REG-*` | 注册/绑定 | 手机号已注册/openid 已绑定 |
| `BIND-*` | 家长绑定 | 邀请码无效/绑定数量超限 |
| `TEST-*` | 五力测试 | 重测限制/画像生成 |
| `TRAIN-*` | 训练模块 | 无画像/题目不足 |
| `ASST-*` | 智能助教 | 轮数满/内容安全 |
| `ADMIN-*` | 管理后台 | 操作权限/配置错误 |
| `SYS-*` | 系统级 | AI 服务不可用/限流 |

**常用错误码：**

| 错误码 | HTTP状态 | 说明 | 用户提示 |
|--------|---------|------|---------|
| `AUTH-001` | 401 | Token 无效或已过期 | 请重新登录 |
| `AUTH-002` | 401 | Token 已在其他设备登录 | 账号已在其他设备登录 |
| `AUTH-003` | 403 | 权限不足 | 暂无权限 |
| `LOGIN-001` | 401 | 用户名/密码错误 | 账号或密码错误，剩余X次机会 |
| `LOGIN-002` | 403 | 账号已锁定 | 账号已锁定，请X分钟后重试 |
| `LOGIN-003` | 403 | 首次登录需改密 | 请先修改初始密码 |
| `SMS-001` | 429 | 发送太频繁 | 请60秒后再试 |
| `SMS-002` | 400 | 验证码错误 | 验证码错误，还可尝试X次 |
| `SMS-003` | 429 | 当日发送超限 | 今日验证码发送次数已达上限 |
| `REG-001` | 409 | 手机号已注册 | 该手机号已注册，请直接登录 |
| `REG-002` | 409 | openid 已绑定 | 当前微信已绑定账号 |
| `BIND-001` | 404 | 邀请码无效/已过期 | 邀请码不存在或已过期 |
| `BIND-002` | 409 | 绑定数量超限 | 最多绑定2位家长 |
| `TEST-001` | 409 | 重测间隔不足 | 距上次测试不足30天，暂不可重测 |
| `TRAIN-001` | 403 | 无五力画像 | 请先完成五力测试 |
| `TRAIN-002` | 400 | 知识点题目不足 | 该知识点题库建设中，暂不支持训练 |
| `ASST-001` | 400 | 对话轮数已满 | 本次对话已达上限，开启新对话继续？ |
| `ASST-002` | 400 | 内容安全拦截 | 该内容无法回复，换个方式试试？ |
| `SYS-001` | 503 | AI 服务暂不可用 | AI助手暂时休息，请稍后再试 |
| `SYS-002` | 429 | 接口限流 | 请求过于频繁，请稍后再试 |

## 2. 认证与账户模块

### 2.1 微信登录（学生/家长）

**接口：** `POST /api/v1/auth/wx-login`
**认证：** 无需 Token
**说明：** 微信授权，通过 code 换取 openid，判断是否已注册

**请求体：**
```json
{
  "code": "wx_auth_code_xxx",
  "user_info": {
    "nickname": "小明",
    "avatar_url": "https://..."
  }
}
```

**响应（新用户，需绑定手机号）：**
```json
{
  "status": "success",
  "code": 0,
  "msg": "授权成功，请绑定手机号",
  "data": {
    "is_new_user": true,
    "temp_token": "临时token，仅用于绑定手机号，有效期10分钟",
    "openid_hash": "用于前端临时存储，不含实际openid"
  }
}
```

**响应（已注册用户）：**
```json
{
  "status": "success",
  "code": 0,
  "msg": "登录成功",
  "data": {
    "is_new_user": false,
    "access_token": "eyJ...",
    "refresh_token": "eyJ...",
    "access_expires_in": 604800,
    "user_info": {
      "student_id": 1001,
      "nickname": "小明",
      "avatar_url": "https://...",
      "grade": "G9",
      "has_five_power_profile": true,
      "recommended_mode": "TRAIN_WEAKNESS"
    }
  }
}
```

**操作数据库：** 查询 `students`（by openid_hash），写入 `students`（新用户）

---

### 2.2 发送短信验证码

**接口：** `POST /api/v1/auth/sms/send`
**认证：** 无需 Token（新注册）或携带 temp_token
**说明：** 发送短信验证码，用于手机号绑定/登录/2FA

**请求体：**
```json
{
  "phone": "13800138000",
  "purpose": "BIND_PHONE"
}
```

`purpose` 可选值：`BIND_PHONE` / `LOGIN` / `TWO_FA`

**响应：**
```json
{
  "status": "success",
  "code": 0,
  "msg": "验证码已发送，5分钟内有效",
  "data": {
    "expire_seconds": 300,
    "cooldown_seconds": 60
  }
}
```

**业务约束：** 同号每60秒仅1次，每日最多10次
**操作数据库：** 写入 `sms_codes`

## 3. 五力认知测试模块

### 3.1 获取测试题卷

**接口：** `GET /api/v1/test/questions`
**认证：** 学生 Token
**说明：** 返回20道固定测试题（按 `display_order` 打散顺序），支持中断恢复

**响应：**
```json
{
  "status": "success",
  "code": 0,
  "msg": "操作成功",
  "data": {
    "session_id": 10001,
    "is_resumed": false,
    "current_question_index": 0,
    "total_questions": 20,
    "questions": [
      {
        "question_id": 5,
        "display_order": 1,
        "question_type": "STANDARD",
        "stem": "有一个封闭房间，里面放着完全相同的三杯热水...",
        "image_url": null,
        "options": [
          { "key": "A", "text": "三个杯子的水最后都会变凉" },
          { "key": "B", "text": "B和C都加了盖，但结果仍然不同" },
          { "key": "C", "text": "A杯没有毛巾" },
          { "key": "D", "text": "实验时间都是20分钟" }
        ],
        "reference_time_sec": 90
      }
    ]
  }
}
```

**业务说明：**
- 若已有 `in_progress` 状态的会话，直接返回该会话及当前进度（`is_resumed: true`）
- `question_type` 前台不展示，用于后端计分路径判断
- 不返回 `option_scores` 和 `option_force_weights`（防止学生猜测测的是什么）

**操作数据库：** 读 `cognitive_test_questions`，读/写 `test_sessions`

---

### 3.2 提交单题答案

**接口：** `POST /api/v1/test/answer`
**认证：** 学生 Token

**请求体：**
```json
{
  "session_id": 10001,
  "question_id": 5,
  "question_index": 0,
  "selected_option": "B",
  "time_spent_sec": 45,
  "modify_count": 1
}
```

**响应：**
```json
{
  "status": "success",
  "code": 0,
  "msg": "答案已记录",
  "data": {
    "answered_count": 1,
    "remaining_count": 19,
    "can_submit": false
  }
}
```

**业务说明：**
- 支持覆盖提交（学生修改答案），以最后一次提交为准
- `time_spent_sec < 5` 时，后端标记 `is_rushed = true`
- 不返回正确/错误，避免影响后续答题行为

**操作数据库：** 写/更新 `test_answer_records`，更新 `test_sessions.current_question_index`

### 3.3 完成测试（触发评分）

**接口：** `POST /api/v1/test/complete`
**认证：** 学生 Token

**请求体：**
```json
{

  "msg": "测试完成，正在生成你的五力画像",
  "data": {
    "profile_id": 2001,
    "forces": {
      "insight":    { "ability": 82, "preference": 34, "final": 69, "level": "strong" },
      "structure":  { "ability": 47, "preference": 18, "final": 41, "level": "weak"   },
      "inference":  { "ability": 74, "preference": 17, "final": 57, "level": "good"   },
      "adaptation": { "ability": 55, "preference": 21, "final": 45, "level": "medium" },
      "transfer":   { "ability": 51, "preference": 10, "final": 39, "level": "weak"   }
    },
    "primary_weakness": "structure",
    "secondary_weakness": "transfer",
    "primary_strength": "insight",

  }

```

**业务说明：**
- 同步返回三层评分结果（ability / preference / final）
- `ai_analysis_text` 由异步任务生成，前端轮询 `GET /api/v1/test/result/{id}` 获取最新状态
- 若 `is_latest` 已有记录，先将旧记录置 `false`

**操作数据库：**
- 更新 `test_sessions.session_status = 'completed'`
- 写入 `five_power_profiles`（`is_latest=true`），旧记录 `is_latest=false`
- 触发 Celery Queue-E：AI分析文字异步生成

## 10. 数据库设计勘误回填

> 本章记录在接口设计过程中发现的数据库设计说明书（`05_数据库设计说明书.md`）中需要补充或修正的内容。

### 10.1 `sms_codes` 表补充 `purpose` 枚举值

**原设计：** `purpose` 可选值为 `REGISTER / LOGIN / TWO_FA`
**补充：** 新增 `BIND_PHONE`（家长首次绑定手机号用途，区别于 `REGISTER`）

```sql
-- 补充枚举值
-- purpose: REGISTER / LOGIN / TWO_FA / BIND_PHONE
```

### 10.2 `test_sessions` 表补充 `total_time_sec` 计算时机

**说明：** `total_time_sec` 在 `POST /api/v1/test/complete` 接口调用时从 `test_answer_records` 聚合计算并写入，表设计已正确，补充注释：

```sql
total_time_sec  INT,  -- 完成测试时写入，= sum(test_answer_records.time_spent_sec)
```

### 10.3 `training_sessions` 表补充 `is_early_end` 字段

**场景：** 学生提前结束训练（不做完5题），需要区分"正常完成"和"提前结束"，生成不同类型的训练小结。

```sql
-- 在 training_sessions 表中新增
is_early_end    BOOLEAN     NOT NULL DEFAULT FALSE,  -- 是否提前结束训练
```

### 10.4 `wrong_answer_records` 表补充 `review_summary` 长度注释

**补充注释：**
```sql
review_summary  TEXT,  -- AI生成的复盘摘要（≤100字），wrong_review 会话结束时写入
```

### 10.5 `cognitive_test_questions` 表补充 `correct_option` 可空说明

**说明：** `OPEN` 类型题目无标准答案，`correct_option` 为 NULL，接口层不返回此字段。

```sql
correct_option  VARCHAR(5),  -- 仅 STANDARD 类型题目有效；OPEN 类型为 NULL
```

### 10.6 统一分页方式说明

接口设计统一使用 **Keyset Pagination（游标分页）**，`05_数据库设计说明书.md` 所有高频列表查询索引已按此优化（包含时间字段的倒序索引），无需修改，补充设计原因说明：

> 使用 `before_id` + `LIMIT` 代替 `OFFSET` + `LIMIT`，避免大数据量下 OFFSET 性能退化，且支持实时数据一致性。
