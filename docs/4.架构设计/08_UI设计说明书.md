## 1. 设计理念与风格

### 1.1 品牌定位

> **智识 × 温度**
> MESH 是一位了解你思维特点的 AI 学习伙伴，不是冷冰冰的做题机器。
> 设计语言应传递：**聪明、专注、有温度、给人信心**。

### 1.2 设计原则

| 原则 | 说明 | 实现方式 |
|------|------|----------|
| **清晰优先** | 学习场景注意力资源有限，每个页面只突出一件事 | 强烈的视觉层级，留白充足 |
| **温暖专业** | 面向13~18岁学生，避免过于冰冷或幼稚 | 柔和圆角，亲切插画，不刻板 |
| **即时反馈** | 答题、AI生成、突破等关键时刻需要强烈的视觉响应 | 动画、状态色、成就感设计 |
| **认知友好** | 数学公式、长文本需要足够的可读性 | 宽松行距，深色文字，代码字体 |
| **一致性** | 相同功能在不同页面表现一致 | 严格的设计 Token 体系 |

### 1.3 整体视觉风格

- **小程序端**：卡片式布局，白底，圆角卡片，深蓝主色，适度渐变
- **管理后台**：简洁表格式，左侧导航，白底灰边，业务效率优先
- **动效**：简洁、目的明确，避免炫技；关键操作配轻量过渡动画

## 附录：交互动效规范

### A. 动效原则

| 原则 | 说明 |
|------|------|
| **目的性** | 每个动效必须服务于用户理解，不能纯装饰 |
| **简短** | 关键动效 150~300ms，过渡动效 200~400ms |
| **一致性** | 相同类型操作使用相同动效曲线 |
| **可关闭** | 提供关闭动效的无障碍选项（prefers-reduced-motion）|

### B. 常用动效规格

| 场景 | 时长 | 缓动曲线 | 方向 |
|------|------|---------|------|
| 页面切换 | 350ms | ease-out | 水平滑动 |
| 底部弹层出现 | 300ms | cubic-bezier(0.16,1,0.3,1) | 上滑 |
| 底部弹层关闭 | 250ms | ease-in | 下滑 |
| 卡片点击反馈 | 150ms | ease-out | scale 0.97 |
| Toast 出现 | 200ms | ease-out | 上移 + 淡入 |
| Toast 消失 | 300ms | ease-in | 淡出 |
| 骨架屏 Shimmer | 1500ms | ease-in-out | 循环 |
| 进度条填充 | 300ms | ease-out | 线性扩展 |
| 理解突破动效 | 400ms | spring | scale 1.05→1 + 粒子 |
| RAG 生成进度 | 持续 | linear | 骨架闪烁 |

### C. 无障碍规范

| 规范 | 要求 |
|------|------|
| 颜色对比度 | 文字与背景对比度 ≥ 4.5:1（WCAG AA）|
| 触摸目标 | 最小触摸区域 44rpx × 44rpx（44px × 44px）|
| 字体缩放 | 支持系统字体放大，布局不破坏 |
| 颜色不独用 | 颜色传达信息时必须同时使用图标/文字辅助 |
| 焦点管理 | 管理后台表单支持键盘 Tab 顺序 |
