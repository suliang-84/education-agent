## 一、设计哲学总述

两张参考图均为金融数据管理后台，共同呈现了「数据密度高、视觉干净、信息层次清晰」的设计语言。核心原则如下：

| 原则 | 说明 |
|------|------|
| **密度优先** | 大量数据行需在有限屏幕内清晰呈现，行高克制，不浪费空间 |
| **色彩功能化** | 颜色只用于传递信息（正/负、激活/静态），不作装饰 |
| **层次靠对比** | 通过字号、字重、颜色透明度建立信息层次，不依赖过多边框/分割线 |
| **数字等宽** | 所有数值强制使用等宽字体，确保列对齐，便于视觉扫描 |
| **交互极简** | 按钮、标签、悬停态均保持克制，避免视觉噪声 |

## 五、共同设计规律提炼

### 5.1 表格设计黄金法则

1. **行高**：带图标行 56px，纯文字行 44-48px，列头行 36-40px
2. **分割线**：极淡（透明度 4-6%），视觉上"感受不到"，靠悬停色强化当前行
3. **列对齐**：名称类左对齐，数字类右对齐，状态类居中
4. **数字处理**：等宽字体（monospace）+ tabular-nums，正负值用颜色区分
5. **小数弱化**：大数字白色/深色，小数部分降透明度或用灰色，视觉权重分离
6. **列头**：比数据行字号小 2-3px，颜色透明度高（muted），不抢眼
7. **操作列**：放最右侧，默认隐藏（或低透明），悬停行时才高亮显示

### 5.2 导航激活态规律

- **浅色**：白色背景 + 细腻阴影 + 深色文字（Tab式）
- **深色**：品牌色实色填充 + 圆角块 + 白色文字（Pill式）
- 两种方式都不用底部色条（underline），避免低级感

### 5.3 徽章/状态标签规律

```
胶囊形（border-radius: 9999px）
内边距：4px 10px（小）/ 6px 14px（中）
字号：11-12px，font-weight: 600
带背景色（半透明）+ 对应文字色
```

### 5.4 按钮层级体系

```
主要操作（Primary CTA）   → 品牌实色背景，白色文字，无边框
次要操作（Secondary）     → 白色/透明背景，品牌色文字，细边框
文字操作（Text）          → 无背景无边框，颜色区分，悬停时有背景
危险操作（Danger）        → 红色系，仅用于确认删除类操作
```

### 5.5 信息密度与留白平衡

- 表格行高宁小勿大，但行内元素（图标、文字）有充足的内边距
- 页面/区块间用较大间距（24-32px）隔离，行内用小间距（8-12px）
- 卡片圆角大（16-18px），产生"浮起"的亲切感，但不增加多余 padding
