## 1. 设计定位

### 1.1 核心叙事

动画描述一个场景：**AI 助教机器人在数字宇宙中守护着学生的认知成长**。机器人是智慧与温暖的化身，环绕它的是五力维度的数据光环和真实运营数据图表，共同构成一幅"用数据点亮教育"的科技画卷。

### 1.2 情感基调

| 维度 | 目标感受 |
|------|---------|
| 第一印象 | 专业可信、科技感强但不冰冷 |
| 情感温度 | 友好亲切，机器人有生命力 |
| 节奏感受 | 平静流动，不急促，像呼吸一样自然 |
| 色彩印象 | 薰衣草紫底色为基，靛蓝科技感为主，局部热粉点睛 |

### 1.3 与管理系统风格的一致性

背景动画的色彩系统直接复用管理系统的设计令牌：

```
底色：#E8ECF8（薰衣草紫，管理系统页面底色）
主色：#4F46E5（靛蓝，品牌主色）
辅色：#F43F7E（热粉，CTA 强调色）
数据色体系：五力维度颜色（洞察力青绿/建构力红/推演力靛蓝/调适力琥珀/迁移力紫）
字体：Inter + JetBrains Mono（与管理系统一致）
卡片圆角：18px（与 .surface 组件一致）
```

## 2. 视觉风格规范

### 2.1 整体风格标签

**软性科技风（Soft Tech）** — 介于硬朗极客风与温暖教育风之间。使用柔和渐变、圆润几何，避免过于锋利的线条和大面积冷钢蓝，用薰衣草紫作为底色调节科技感与亲和力的平衡。

### 2.2 配色方案

#### 背景层
```
主底色：#E8ECF8（薰衣草紫）
深浅渐变：顶部 #EEF0FA → 底部 #DDE3F4
光斑色：
  - 靛蓝光斑：#818CF8，opacity 0.35，blur 90px
  - 粉色光斑：#F9A8D4，opacity 0.25，blur 80px
  - 青绿光斑：#5EEAD4，opacity 0.22，blur 70px
```

#### 角色层（机器人）
```
主体填充：#4F46E5（靛蓝）
高光区域：#818CF8（淡靛蓝，机器人顶部反光）
眼睛白：#FFFFFF
瞳孔：#1E293B（深蓝灰）
腮红：#F43F7E（热粉）
触角发光：#818CF8 ↔ #F43F7E 渐变闪烁
机械细节：#6366F1（中靛蓝）
```

#### 学生角色
```
人形轮廓：白色线稿，opacity 0.75
光环：对应五力维度色
```

#### 数据卡片
```
卡片背景：rgba(255,255,255,0.72)
卡片边框：rgba(255,255,255,0.65)
内文主色：#1E293B
数据强调：对应维度色
```

### 2.3 光效规范

| 效果 | 参数 |
|------|------|
| 背景光晕 | `filter: blur(80-90px)`，位置缓慢漂移 |
| 粒子发光 | `drop-shadow(0 0 4px currentColor)` |
| 卡片阴影 | `0 8px 32px rgba(79,70,229,0.14)` |
| 数据线条 | 渐变描边，首尾透明 |
| 连接射线 | 虚线描边，流动动画 |

## 3. 场景结构与构图

### 3.1 空间分层（从后到前）

```
Layer 0 — 背景底色渐变（静态）
Layer 1 — 漂浮光斑（3个，极缓漂移）

## 4. 角色元素设计

### 4.1 AI 助教机器人

#### 4.1.1 外形设计

```
整体比例：头身比约 1:1.2（萌系卡通机器人，非写实）
头部：圆形，半径 40px（缩放1.0时）
  - 材质：哑光金属感，靛蓝主色（#4F46E5）
  - 顶部高光：左上角椭圆反光（#818CF8，opacity 0.4）
  - 正面有机械纹理线条（极细，opacity 0.15）

触角：
  - 单根，从头顶中央垂直延伸 22px
  - 末端：圆形发光球（radius 7px）
  - 发光色：靛蓝↔热粉渐变闪烁，2秒周期

眼睛：
  - 大圆眼，白色圆底（radius 9px）
  - 瞳孔：深色实心圆（radius 5px），带高光点
  - 眼神：自然左右轻微游移，4秒周期
  - 眨眼：随机每6-10秒触发一次

腮红：
  - 双侧各3个小圆点，热粉色（#F43F7E）
  - 排列成弧形，暗示笑脸

嘴巴：
  - 弧形上扬的微笑路径（stroke，white）
  - 随机轻微动态：偶尔"说话"张闭（0.5秒）

身体：
  - 圆角矩形，宽60px 高50px，靛蓝（比头部略深，#4338CA）
  - 中央胸口屏：小圆角矩形，显示实时迷你柱状图
  - 胸口4根柱子颜色：热粉/青绿/琥珀/靛蓝
  - 顶部高光条：rgba(255,255,255,0.15)

手臂：
  - 左臂：持续挥手动作，±30° 弧形摆动，1.5秒周期
  - 右臂：静态，末端持有一颗发光小星星（琥珀色✦）

腿部：
  - 两条短腿，圆角矩形
  - 末端椭圆形脚掌
  - 地面有极淡阴影投影（indigo，opacity 0.1）
```

#### 4.1.2 机器人悬浮动画

```
上下漂浮：
  - 振幅：±6px，正弦函数
  - 周期：3.5秒
  - 缓动：ease-in-out（自然呼吸感）

地面阴影跟随：
  - 机器人上浮时阴影缩小、透明度降低
  - 机器人下落时阴影扩大、透明度升高
```

#### 4.1.3 机器人光环（五力辐射环）

```
结构：5层同心圆弧环，从内到外渐大
  - 内环直径：90px（密集轨道线）
  - 外环直径：200px（稀疏弧线）

轨道弧线：
  - 每层2-3段弧，颜色对应五力：
    · 内层1：青绿（洞察力）
    · 内层2：红色（建构力）
    · 中层：靛蓝（推演力）
    · 外层1：琥珀（调适力）
    · 外层2：紫色（迁移力）
  - 各层以不同速度旋转（20-45秒/转），方向交替

轨道粒子：
  - 每条轨道上有1-2颗发光粒子沿轨运动
  - 粒子颜色 = 轨道颜色，radius 4-6px
  - 带发光尾迹（motion blur 效果）
```

### 4.2 学生人形剪影

#### 4.2.1 外形设计

```
风格：简化线稿剪影，非写实
形态：半身/全身学生形象，头戴耳机（强调学习场景）
配色：白色线条，opacity 0.55-0.75
位置：画面左侧中部，略微偏后（z-index 低于机器人）

组合方式：
  - 2-3个剪影分布在不同位置
  - 大小不一（近大远小）
  - 有的在"答题"（低头看题），有的在"思考"（抬头仰望机器人）

特殊效果：
  - 每个学生剪影头顶有对应的五力维度数值浮动显示
    如：洞察力 82 ↑（青绿色文字，等宽字体）
  - 维度数值有轻微上浮动画，暗示成长感
```

#### 4.2.2 学生与机器人互动

```
连接线：
  - 从机器人发出的虚线连接至学生剪影
  - 线条颜色：对应该学生当前训练的五力维度色
  - 线条上有数据粒子从机器人流向学生（方向感：AI给学生传递知识）
  - 偶尔方向反转：学生作答数据回传机器人（双向交互）

思考气泡（偶发，每8秒随机触发一次）：
  - 学生头顶出现数学/物理公式气泡
  - 气泡内容：简单公式，如 F=ma、y=kx+b
  - 出现1.5秒后淡出
```

## 5. 五力视觉元素设计

### 5.1 五力雷达图（核心图表）

#### 5.1.1 样式规范

```
容器：白色圆角卡片，radius 18px，backdrop-filter blur(12px)
  尺寸：约 240×240px（含标题和标签）
  位置：画面中央偏左区域

雷达图本体：
  - 五边形网格，5层同心五边形
  - 网格线：rgba(79,70,229,0.12)
  - 轴线：rgba(79,70,229,0.18)

数据多边形：
  - 填充：rgba(79,70,229,0.15)
  - 描边：#4F46E5，width 2px
  - 顶点圆：各维度颜色，radius 5px

维度标签（胶囊形）：
  - 洞察力：青绿底白字（#0D9488）
  - 建构力：红底白字（#E11D48）
  - 推演力：靛蓝底白字（#4F46E5）
  - 调适力：琥珀底白字（#D97706）
  - 迁移力：紫底白字（#7C3AED）
  - 字体：Inter 11.5px Bold
```

#### 5.1.2 雷达图动画

```
初始状态（循环重置点）：
  - 数据多边形从中心以0%占比开始

展开动画（0→4秒）：
  - 各顶点从圆心向外延伸
  - easeOut cubic 缓动
  - 5个顶点顺序依次展开，间隔 0.15s

脉冲动画（4-8秒，保持态）：
  - 各维度数值轻微呼吸浮动（±3%幅度）
  - 最弱维度（建构力47）额外有"提升提示"动效：
    该顶点位置冒出"+2"的小标注，淡入淡出

维度数值计数动画（随雷达图展开同步）：
  - 对应各维度标签内显示数值从0逐渐计数至最终值
  - JetBrains Mono 等宽字体
```

### 5.2 五力标签轨道漂浮

```
位置：5个标签在机器人光环外围漂浮
运动：椭圆轨道，各标签轨道参数不同

运动参数：
  洞察力：轨道半径x 95px，y 38px，速度 0.022 rad/frame，相位 0
  建构力：轨道半径x 88px，y 32px，速度 0.019 rad/frame，相位 π*0.4
  推演力：轨道半径x 100px，y 40px，速度 0.025 rad/frame，相位 π*0.8
  调适力：轨道半径x 92px，y 35px，速度 0.018 rad/frame，相位 π*1.2
  迁移力：轨道半径x 96px，y 37px，速度 0.021 rad/frame，相位 π*1.6

标签样式：圆角胶囊，对应维度背景色，白色文字
  padding: 4px 12px，radius: 12px，font: 12px Inter Bold
```

## 6. 数据图表元素设计

### 6.1 柱状图卡片（主图表）

```
位置：画面右上区域
容器尺寸：300×180px，圆角卡片（radius 18px）
标题："学习数据统计"，Inter 14px Bold，#1E293B

柱子配置（4根）：
  ┌──────────────────────────────┐
  │  学习数据统计                │
  │                              │
  │  ████ ████  ███  ██         │
  │  靛蓝  粉   青绿  琥珀       │
  │  2847  142  72%  312        │
  │  学生  训练  正确 RAG        │
  └──────────────────────────────┘

柱子颜色：
  - 学生总数：#4F46E5（靛蓝）
  - 今日训练：#F43F7E（热粉）
  - 正确率：#0D9488（青绿）
  - RAG调用：#D97706（琥珀）

柱子动画：
  - 从底部向上生长，easeOut，各柱间隔 0.12s 启动
  - 顶部有白色高光层（opacity 0.28）
  - 完全展开后轻微呼吸抖动（±2px，2秒周期）
  - 每4秒数值轻微随机波动（±5%），暗示实时数据
```

### 6.2 小型统计卡片（4张散布）

#### 卡片样式规范
```
尺寸：140-160px 宽，48-60px 高
圆角：14px
背景：rgba(255,255,255,0.78)
顶部色条：对应数据类型颜色（高度 4px）
阴影：0 4px 16px rgba(79,70,229,0.10)
```

#### 4张卡片内容与位置

```
卡片①「今日新增」
  位置：左上角，稍微旋转 -3°
  颜色：靛蓝（#4F46E5）
  数值：+12（大字，等宽字体）
  副标签：今日新增学生

卡片②「今日成本」
  位置：右下角，旋转 3°
  颜色：紫色（#7C3AED）
  数值：$3.47（JetBrains Mono）
  副标签：AI Token 费用

卡片③「平均正确率」
  位置：右上角，旋转 -2.5°
  颜色：青绿（#0D9488）
  数值：72%
  副标签：本周训练正确率

卡片④「待审核」
  位置：底部偏左，旋转 2°
  颜色：热粉（#F43F7E）
  数值：45
  副标签：待审核 AI 标注
```

#### 卡片动画
```
入场：从对应角落方向滑入 + 淡入，easeOut spring
  - 滑入位移：±20px，透明度 0→1
  - 各卡片入场间隔 0.2s

保持态：
  - 轻微上下漂浮（±4px，4-6秒周期，各卡片周期略不同）
  - 旋转角度在原始角度基础上轻微颤动（±0.5°）

数值跳动：
  - 每5-8秒随机触发一次数值轻微变动
  - 数值闪烁更新（0.2秒内淡出→新值淡入）
```

### 6.3 数据流连接线

```
连接机器人与各图表之间的数据流可视化

样式：
  - 虚线段，strokeDasharray: "6 4"
  - 颜色：对应连接图表的主色，opacity 0.35
  - 线宽：1.5px

动画：
  - strokeDashoffset 动画，速度 40px/s
  - 制造数据持续流动的视觉效果
  - 正向（机器人→图表）：AI输出分析
  - 逆向（图表→机器人）：数据回传
  - 两个方向交替，每 3秒切换一次方向

节点：
  - 线段末尾有小圆点（radius 3px）
  - 小圆点到达终点时有短暂发光效果（scale 1→2→1，0.3s）
```

## 7. 环境与氛围元素

### 7.1 背景光斑（Ambient Glow）

```
光斑①（靛蓝主光）
  形状：椭圆，宽 520px，高 520px
  颜色：#818CF8
  位置：左上角，中心在 (-80, -80) 附近
  opacity：0.38
  模糊：filter blur(90px)
  漂移轨迹：以 (−60, −60) 为中心，±35px 缓慢游移
  周期：16秒

光斑②（粉色）
  形状：椭圆，宽 400px，高 400px
  颜色：#F9A8D4
  位置：左下角，中心约 (350, 650)
  opacity：0.30，blur 80px
  漂移：±28px，12秒周期，与光斑①相位差 5s

光斑③（青绿）
  形状：圆，径 340px
  颜色：#5EEAD4
  位置：中央偏左，约 (480, 180)
  opacity：0.22，blur 70px
  漂移：±22px，10秒周期，相位差 8s
```

### 7.2 粒子群（Particles）

```
数量：22 颗
分布：随机散布全画面（种子固定，保证一致性）
粒子类型：
  - 普通圆点：radius 2-4px，各维度色系
  - 星形粒子（30%）：4条射线，"✦"形，radius 3-5px
  - 大粒子（10%）：radius 5-7px，带发光 drop-shadow

运动特征：
  - 每颗粒子有独立的椭圆漂浮轨道
  - x轴振幅：10-28px
  - y轴振幅：0.75x 比例
  - 速度：0.018-0.065 rad/frame（各自随机）
  - 亮度呼吸：opacity 在 0.25-0.85 间按正弦变化

颜色分布：
  靛蓝(#818CF8) / 热粉(#F9A8D4) / 青绿(#5EEAD4)

## 8. 动画时序编排

### 8.1 8秒完整时序表

```
时间轴（0-240帧，30fps）：

帧 0-20（0-0.67s）：全局淡入
  ├─ 背景底色：瞬间到位
  ├─ 光斑：opacity 0→目标值，ease-out
  └─ 标题文字：translateY(-8px,0) + opacity 0→1

帧 0-27（0-0.9s）：机器人入场
  ├─ 从画面底部外侧（y+140px）弹入
  ├─ easeOut spring（略微过冲后回弹）
  └─ 到位后开始悬浮循环

帧 15-130（0.5-4.3s）：五力雷达图展开
  ├─ 帧15：雷达图卡片淡入（opacity 0→1）
  ├─ 帧20-130：雷达图多边形从中心向外生长
  ├─ 5个维度顶点按顺序延迟启动（各4帧间隔）
  └─ 同步：维度数值从0计数至最终值

帧 90-240（3-8s）：柱状图入场
  ├─ 帧90：卡片容器淡入
  └─ 帧96-168：4根柱子依次从底部生长

帧 60-60（2s，一次）：粒子群出现
  └─ 各粒子随机位置淡入，散开进入轨道

帧 54-114（1.8-3.8s）：小型统计卡片入场
  ├─ 帧54：卡片①从左上滑入
  ├─ 帧66：卡片②从右下滑入
  ├─ 帧78：卡片③从右上滑入
  └─ 帧90：卡片④从左下滑入

帧 50-240（1.7s-end）：学生剪影显现
  ├─ 渐渐浮现（opacity 0→0.65，缓慢淡入）
  └─ 头顶维度数值同步出现

帧 0-240（全程循环）：
  ├─ 机器人：悬浮 + 挥手 + 眨眼 + 胸口图表动态
  ├─ 光斑：3个光斑各自漂移
  ├─ 粒子群：22颗粒子各自轨道运动
  ├─ 五力轨道环：5层不同速度旋转
  ├─ 数据流线：机器人↔图表 虚线流动
  └─ 小卡片：数值随机跳动
```

### 8.2 情绪节奏曲线

```
0-1s：平静涌现（元素陆续出现，节奏缓）
1-4s：生长高潮（雷达图展开是视觉焦点，节奏适中）
4-6s：补充完善（图表和卡片完成，整体丰富起来）
6-8s：平稳呼吸（所有元素进入保持态，轻微律动）
→ 无缝衔接回0s
```

## 9. 循环衔接设计

### 9.1 无缝循环策略

```
淡出区间：第 7.5-8s（帧 225-240）
  - 全局 opacity 遮罩从 0 渐变至 1.0
  - 遮罩颜色：#E8ECF8（背景底色）
  - 曲线：linear（匀速，避免突兀）

淡入区间：第 0-0.5s（帧 0-15）
  - 全局遮罩从 1.0 渐变至 0
  - 同步所有元素开始入场动画

视觉连续性保证：
  - 淡出结束时画面为纯底色
  - 淡入开始时背景光斑已在原位（瞬间就位）
  - 视觉上：底色→光斑→元素，层层显现，感觉自然
```

### 9.2 持续动画元素（不受循环影响）

以下元素使用无限循环动画，与全局序列解耦，确保不会因重置而产生跳帧：

```
- 机器人悬浮（sin 函数，数学连续）
- 机器人挥手（sin 函数）
- 背景光斑漂移（sin 函数，长周期 10-16s）
- 粒子轨道（sin/cos 函数，各自长周期）
- 五力轨道环旋转（线性，长周期 20-45s）
- 数据流虚线（strokeDashoffset 线性动画）
```

### 10.4 性能考虑

```

  - 使用 CSS 背景 + keyframe 动画模拟光斑漂移
  - 3个光斑用 radial-gradient + animation 实现

  - 检测到此媒体查询时，只保留静态背景
  - 关闭所有粒子、旋转、漂移动画
  - 仅保留一张静态截帧图片

移动端适配：
  - 视口宽度 < 768px 时，隐藏视频背景
  - 改用静态渐变背景（#E8ECF8 → #DDE3F4）
```
